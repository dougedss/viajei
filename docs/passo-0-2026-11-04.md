## 2. Ajustes propostos ao prompt (regra 8)

| # | Ajuste | Por quê |
|---|---|---|
| 1 | **Conflito resolvido por coluna, não por linha** (`field_versions jsonb`) | O trigger por linha descarta o patch antigo inteiro. Exemplo: passageiro sem sinal toca "Chegamos!" às 14:00; às 14:30 alguém em casa edita a observação da mesma parada; às 15:00 o carro pega sinal e o `done_at` é descartado. Com versão por coluna, as duas edições ficam. |
| 2 | **Push ordenado por tabela depois de coalescer** | FIFO com coalescência quebra FKs: crio P no dia D1, crio D2, movo P para D2; a coalescência funde criação e movimento de P na primeira posição, e P chega antes de D2. Ordenar o lote por nível (viagem → dia → parada → filhos) e aplicar numa transação. |
| 3 | **IDs determinísticos (UUID v5) quando há chave natural** | Dois celulares sem sinal criam o "Dia 12/12"; o segundo esbarra no `unique`. Com `id = v5(trip_id, data)` os dois escrevem a mesma linha. Vale para dias, convites, memórias, conquistas, eventos de XP, missões sugeridas, trilhas gravadas. `check` no banco confere o id. |
| 4 | **Dias derivados das datas da viagem**, sem `position` | Com `unique (trip_id, date)` a ordem já é a data. |
| 5 | **Ordem das paradas com índice fracionário** (`position text collate "C"`) | Renumerar gera N patches a cada arrasto e reordenações simultâneas se misturam. |
| 6 | **Memória por pessoa** (`stop_memories`) | Nota e texto na própria parada fariam duas pessoas sobrescreverem uma à outra. |
| 7 | **Convite só com e-mail confirmado**, policies sem o e-mail do JWT | Sem isso, quem criar conta com o seu e-mail, antes de confirmar, vê e reivindica seus convites. Exige SMTP próprio. |
| 8 | **Exclusão de viagem soft** (só o dono), com expurgo depois | Hard delete não deixa lápide. Membro removido ou viagem expurgada: `sync_pull` responde `revoked` e o app limpa os dados locais. |
| 9 | **Funções security definer no schema `private`** | Recomendação do Supabase; em `public` ficariam expostas como RPC. |
| 10 | **Um aviso Realtime por transação e por viagem** | Importação de 80 linhas geraria 80 broadcasts por aparelho. |
| 11 | **Arquivos imutáveis no Storage** (sem policy de update) | Trocar o arquivo no mesmo caminho deixaria o Blob em cache desatualizado. |
| 12 | **Códigos de domínio em inglês** | O prompt mistura `vinicola`/`natureza` com `attraction`/`before`. Rótulos pt-BR em `_shared/constants.ts`. |
| 13 | **Carro em três colunas** (`car_model`, `car_color`, `car_accessories text[]`) | Com resolução por coluna, troca de cor e acessório novo em paralelo se juntam. |
| 14 | **Semântica da trilha** | O carro fica no último nó concluído, o halo pulsa no próximo, "Partiu!" põe o carro na estrada. |
| 15 | **Chaves novas do Supabase** | `anon`/`service_role` serão descontinuadas até o fim de 2026. `VITE_SUPABASE_PUBLISHABLE_KEY`; Edge Function com `withSupabase({ auth: 'user' })`, `verify_jwt` ligado. Nenhuma chave secreta no client. |
| 16 | **CRUD de viagens sai da fase 1 e vai para a 2** | Na fase 1 seria online direto e reescrito sobre o Dexie na 2. |
| 17 | **XP de equipe** | Cada evento tem dono definido; cada aparelho deriva o XP do estado compartilhado e grava o próprio evento. |

Códigos: tipos de parada `origin/transit/nature/winery/hotel/food/event/city/other`; reservas `hotel/ticket/restaurant/other`; gastos `lodging/fuel/food/attractions/other`.

## 4. Como o offline funciona

```
 Toque em "Chegamos!"
        │
        ▼
 ┌──────────── uma transação Dexie (atômica) ─────────────┐
 │ stops.update(id, {done_at})  +  outbox.add(patch)       │   UI e fila nunca divergem
 └─────────────────────────────────────────────────────────┘
        │ useLiveQuery redesenha na hora, com ou sem rede
        ▼
 Motor de sync: uma aba por vez (Web Locks API)
 gatilhos: escrita · online · foco · abrir o app · aviso do Realtime · 60 s visível
        │
        ▼
 1. PUSH   coalesce(outbox) → ordena por tabela → rpc sync_push(lote ≤ 200)
           por operação: applied · ignored · stale · error
           applied / ignored / stale → sai da fila (stale mostra aviso discreto)
           error de rede → backoff 1 s, 2 s, 4 s… até 60 s; após 5 tentativas → "Pendentes"
           error de regra (check, RLS) → direto para "Pendentes", sem insistir
        │
        ▼
 Postgres, como o usuário (RLS vale)
   before: sync_guard   → colunas imutáveis, versão por coluna, synced_at
   after : broadcast    → 1 aviso por viagem por transação no tópico trip:<id>
        │                                   │
        │                                   └──► Realtime ──► outros aparelhos agendam pull (800 ms)
        ▼
 2. PULL   rpc sync_pull(trip, cursor − 5 s) → linhas com synced_at > cursor
        │
        ▼
 applyPull, numa transação Dexie:
   upsert das linhas · lápide remove a linha e seus filhos locais
   linhas com pendência na outbox recebem as mudanças pendentes por cima (sem "piscar")
   revoked → apaga a viagem local e avisa
   cursor ← server_time
```

- `mutate(table, id, changes)` é a única porta de escrita: escrita local e fila na mesma transação.
- 5 s de sobreposição no pull: `synced_at` é atribuído antes do commit; o upsert local é idempotente.
- Relógio adiantado: o servidor limita qualquer versão a "agora + 2 min".
- Anexos: fila baixa cada arquivo com `storage.download` e guarda o Blob no Dexie; `navigator.storage.persist()` na instalação.
- Sessão por `getSession()`, nunca `getUser()`. Conectividade = eventos `online`/`offline` + resultado real das requisições.
- Service worker: precache da casca, fontes e ícones; `navigateFallback`; `CacheFirst` para tiles do OSM (30 dias, limite de entradas); aviso de nova versão.

## 5. Modelo de dados e RLS

Todas as tabelas sincronizadas levam as **colunas de sync**: `created_at timestamptz not null default now()`, `updated_at timestamptz not null`, `field_versions jsonb not null default '{}'`, `synced_at timestamptz not null` e, nas tabelas da viagem, `deleted_at timestamptz`. Abaixo, `<colunas de sync>`.

### 0001_fundacao.sql (fase 1)
```sql
create extension if not exists "uuid-ossp" with schema extensions;   -- uuid_generate_v5
create schema if not exists private;                                 -- fora dos "exposed schemas"
revoke all on schema private from public, anon;
grant usage on schema private to authenticated;
alter default privileges in schema public revoke all on tables    from anon;
alter default privileges in schema public revoke all on functions from anon, public;

-- cast seguro: caminho ou tópico malformado vira null (nega acesso) em vez de erro
create function private.uuid_or_null(p text) returns uuid
language plpgsql immutable set search_path = '' as $$
begin return p::uuid; exception when invalid_text_representation then return null; end $$;

-- registro das tabelas sincronizadas: whitelist do push, roteiro do pull, ordem topológica
create table private.sync_tables (
  name  text primary key,
  scope text not null check (scope in ('trip', 'user')),
  mode  text not null check (mode in ('lww', 'append')),
  rank  smallint not null                                   -- pais antes de filhos
);
grant select on private.sync_tables to authenticated;

-- imutáveis, versão por coluna (LWW), synced_at
create function private.sync_guard() returns trigger
language plpgsql set search_path = '' as $$
declare
  v_now timestamptz := clock_timestamp();
  v_cap timestamptz := clock_timestamp() + interval '2 minutes';
  v_new jsonb := to_jsonb(new);
  v_old jsonb;
  v_in  jsonb;
  v_ver jsonb;
  v_col text;
  v_ts  timestamptz;
  v_won boolean := false;
begin
  if tg_op = 'INSERT' then
    new.updated_at     := least(coalesce(new.updated_at, v_now), v_cap);
    new.field_versions := jsonb_build_object('*', new.updated_at) || coalesce(
      (select jsonb_object_agg(key, least((value #>> '{}')::timestamptz, v_cap))
         from jsonb_each(new.field_versions)), '{}');
    new.synced_at := v_now;
    return new;
  end if;

  v_old := to_jsonb(old);
  foreach v_col in array array['id', 'created_at'] || tg_argv loop
    if v_new -> v_col is distinct from v_old -> v_col then
      raise exception 'a coluna % não pode mudar', v_col using errcode = '42501';
    end if;
  end loop;

  -- versões declaradas por esta escrita; escrita sem versões (RPC do servidor) usa a hora do servidor
  v_in  := case when new.field_versions is distinct from old.field_versions
                then new.field_versions else '{}'::jsonb end;
  v_ver := old.field_versions;

  for v_col in select jsonb_object_keys(v_new) loop
    continue when v_col in ('id', 'created_at', 'updated_at', 'synced_at', 'field_versions');
    continue when (v_new -> v_col) is not distinct from (v_old -> v_col) and not (v_in ? v_col);
    v_ts := least(coalesce((v_in ->> v_col)::timestamptz, v_now), v_cap);
    if v_ts >= coalesce((v_ver ->> v_col)::timestamptz, (v_ver ->> '*')::timestamptz, '-infinity') then
      v_ver := v_ver || jsonb_build_object(v_col, v_ts);
      v_won := true;
    else
      v_new := jsonb_set(v_new, array[v_col], v_old -> v_col);   -- servidor tem versão mais nova
    end if;
  end loop;

  if not v_won then return null; end if;                          -- nada novo: escrita antiga (stale)
  new := jsonb_populate_record(new, v_new);
  new.field_versions := v_ver;
  new.updated_at := greatest(old.updated_at,
    (select max((value #>> '{}')::timestamptz) from jsonb_each(v_ver)));
  new.synced_at := v_now;
  return new;
end $$;

-- aviso Realtime: só {} no tópico; um por viagem por transação
create function private.broadcast_trip_change() returns trigger
language plpgsql security definer set search_path = '' as $$
declare
  v_trip uuid := (to_jsonb(new) ->> tg_argv[0])::uuid;
  v_sent text := coalesce(current_setting('viajei.notified', true), '');
begin
  if position(v_trip::text in v_sent) = 0 then
    perform realtime.send('{}'::jsonb, 'change', 'trip:' || v_trip, true);
    perform set_config('viajei.notified', v_sent || v_trip || ',', true);
  end if;
  return null;
end $$;

-- tabelas somente-anexar
create function private.stamp_synced() returns trigger
language plpgsql set search_path = '' as $$
begin new.synced_at := clock_timestamp(); return new; end $$;
```

  execute format('create trigger d_broadcast after insert or update on public.%I for each row execute function private.broadcast_trip_change(''trip_id'')', p_table);

create function public.sync_push(p_ops jsonb) returns jsonb
language plpgsql security invoker set search_path = '' as $$
declare
  v_op jsonb; v_t private.sync_tables; v_vals jsonb; v_cols text; v_n integer;
  v_ver jsonb; v_status text; v_lost jsonb; v_out jsonb := '[]';
begin
  if jsonb_typeof(p_ops) is distinct from 'array' or jsonb_array_length(p_ops) > 200 then
    raise exception 'lote inválido' using errcode = '22023';
  end if;
  for v_op in select value from jsonb_array_elements(p_ops) loop
    begin                                                          -- savepoint por operação
      select * into strict v_t from private.sync_tables where name = v_op ->> 'table';   -- whitelist
      v_vals := (v_op -> 'values') || jsonb_build_object('id', v_op -> 'id',
                  'updated_at', v_op -> 'updated_at', 'field_versions', v_op -> 'versions');
      v_status := null; v_lost := '[]';

      if v_op ->> 'op' = 'upsert' or v_t.mode = 'append' then
        select string_agg(format('%I', a.attname), ', ') into v_cols
          from pg_attribute a
         where a.attrelid = format('public.%I', v_t.name)::regclass and a.attnum > 0 and not a.attisdropped
           and a.attname not in ('synced_at', 'created_at') and v_vals ? a.attname;
        execute format('insert into public.%I (%s) select %s from jsonb_populate_record(null::public.%I, $1) on conflict (id) do nothing',
                       v_t.name, v_cols, v_cols, v_t.name) using v_vals;
        get diagnostics v_n = row_count;
        if v_n = 1 then v_status := 'applied';
        elsif v_t.mode = 'append' then v_status := 'ignored';
        end if;
      end if;

      if v_status is null then                                     -- patch, ou upsert de linha existente
        select string_agg(format('%I', a.attname), ', ') into v_cols
          from pg_attribute a
         where a.attrelid = format('public.%I', v_t.name)::regclass and a.attnum > 0 and not a.attisdropped
           and a.attname not in ('id', 'synced_at', 'created_at') and v_vals ? a.attname;
        execute format('update public.%I set (%s) = (select %s from jsonb_populate_record(null::public.%I, $1)) where id = $2 returning field_versions',
                       v_t.name, v_cols, v_cols, v_t.name) into v_ver using v_vals, (v_op ->> 'id')::uuid;
        get diagnostics v_n = row_count;
        if v_n = 1 then
          v_status := 'applied';
          select coalesce(jsonb_agg(k), '[]') into v_lost          -- colunas em que outra edição venceu
            from jsonb_object_keys(v_op -> 'versions') k
           where (v_ver ->> k)::timestamptz is distinct from (v_op -> 'versions' ->> k)::timestamptz;
        else
          execute format('select count(*) from public.%I where id = $1', v_t.name) into v_n using (v_op ->> 'id')::uuid;
          v_status := case when v_n = 1 then 'stale' else 'error' end;   -- invisível = inexistente ou sem acesso
        end if;
      end if;
      v_out := v_out || jsonb_build_object('seq', v_op -> 'seq', 'status', v_status, 'superseded', v_lost);
    exception when others then
      v_out := v_out || jsonb_build_object('seq', v_op -> 'seq', 'status', 'error', 'code', sqlstate, 'message', sqlerrm);
    end;
  end loop;
  return v_out;
end $$;

create function public.sync_pull(p_trip_id uuid, p_since timestamptz) returns jsonb
language plpgsql stable security invoker set search_path = '' as $$
declare v_out jsonb := jsonb_build_object('server_time', now()); v_t text; v_rows jsonb;
begin
  if not private.is_trip_member(p_trip_id) then
    return v_out || jsonb_build_object('revoked', true);
  end if;
  select coalesce(jsonb_agg(to_jsonb(t) - 'field_versions'), '[]') into v_rows
    from public.trips t where t.id = p_trip_id and t.synced_at > p_since;
  v_out := v_out || jsonb_build_object('trips', v_rows);
  for v_t in select name from private.sync_tables where scope = 'trip' and name <> 'trips' order by rank loop
    execute format('select coalesce(jsonb_agg(to_jsonb(x) - ''field_versions''), ''[]'') from public.%I x where x.trip_id = $1 and x.synced_at > $2', v_t)
      into v_rows using p_trip_id, p_since;
    v_out := v_out || jsonb_build_object(v_t, v_rows);
  end loop;
  -- perfis: os que mudaram e os de quem entrou desde o cursor
  select coalesce(jsonb_agg(to_jsonb(p) - 'field_versions'), '[]') into v_rows
    from public.profiles p
    join public.trip_members m on m.user_id = p.id and m.trip_id = p_trip_id
   where m.status = 'accepted' and m.deleted_at is null and (p.synced_at > p_since or m.synced_at > p_since);
  return v_out || jsonb_build_object('profiles', v_rows);
end $$;

create function public.sync_pull_user(p_since timestamptz) returns jsonb
language plpgsql stable security invoker set search_path = '' as $$
declare v_out jsonb := jsonb_build_object('server_time', now()); v_t text; v_rows jsonb;
begin
  -- índice de viagens do usuário: é assim que um aparelho novo descobre o que puxar
  select coalesce(jsonb_agg(to_jsonb(m) - 'field_versions'), '[]') into v_rows
    from public.trip_members m where m.user_id = (select auth.uid()) and m.synced_at > p_since;
  v_out := v_out || jsonb_build_object('memberships', v_rows);
  for v_t in select name from private.sync_tables where scope = 'user' order by rank loop
    execute format('select coalesce(jsonb_agg(x), ''[]'') from public.%I x where x.user_id = $1 and x.synced_at > $2', v_t)
      into v_rows using auth.uid(), p_since;
    v_out := v_out || jsonb_build_object(v_t, v_rows);
  end loop;
  return v_out;
end $$;

revoke execute on function public.sync_push(jsonb), public.sync_pull(uuid, timestamptz),
  public.sync_pull_user(timestamptz) from public, anon;
grant execute on function public.sync_push(jsonb), public.sync_pull(uuid, timestamptz),
  public.sync_pull_user(timestamptz) to authenticated;
