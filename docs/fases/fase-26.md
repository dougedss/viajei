1. **Comece:** caffeinate, identidades, leitura (as ideias inteiras; a D296 com os achados; a memória da regra nova do laboratório), `git fetch --prune origin && git checkout -b fase-26 origin/main`, `git status` (só os itens da seção 1 fora do git), e a 3.0 (os artefatos do run 45040801438; a `medir-desempenho` só se eles não bastarem).
